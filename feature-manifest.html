产品定位

用社会科学看社会 —— 将高大上的理论落地到社会生活的实践中。网站包含两个页面：

📌 命名约定

"HTML" = 本功能说明文档（契约文件）
"网站" = sociology-map.html（实际产品）

  • 社会热点（首页）：每日抓取新闻，用社会科学理论解读，让理论接地气
  • 知识图谱：311个节点（社会学107·经济学102·心理学102；社会学含思想家33·理论21·概念35·领域18，经济/心理各思想家29·理论21·概念34·领域18），采用力导向有机布局（学科以外环颜色区分、可选时间轴 X 约束——刻度仅在有节点的年段绘制），展示社会科学三大领域理论的发展脉络与跨学科网络

双页面架构

网站采用双页面架构，通过顶部 Tab 切换。两个页面共享同一套 CSS 变量和部分组件（如详情面板），但各自独立渲染。

[A8] 新闻详情面板

📍 两页面通用 · 右侧滑出覆盖层 HTML + CSS + JS

点击新闻卡片后从右侧滑出（宽440px），显示完整的新闻解读。面板内容分4个区块：

  1. 💡 一句话立论 — gist：开篇用一句大白话点明这条新闻背后的社会科学内核（替代旧版"背景"长段）。
  2. 🧵 事件脉络 — thread：把"背景-发展-结果"串成有序时间线（每步含时间点 t + 说明 x），让读者一秒看清来龙去脉。
  3. 🔍 社科视角解读 — 以读者真问题驱动的 interpretations 数组（取代旧版 perspectives），每条解读分：
    • ❓ 真问题 q（你真正会问的疑问，如"为什么大家突然不说话了？"）
    • 🚫 常识误判 naive（"常以为…"的直觉误区）
    • 🔎 透镜 badge：用「理论名」解读的标签（lens / lensId ∈ 节点集）
    • 📚 学术解读 body（含 <b>理论名</b> 高亮，引用理论家）
    • 💡 顿悟 aha：以"所以…"收尾的恍然大悟
    • 📄 前沿研究（内嵌，可选） — 若某解读有直接相关的前沿国内外研究，该解读内直接内嵌研究卡（标题/外链/年份·期刊·作者/一句白话解读），并附其上游知识节点的「溯源 → B」按钮（focusNode(B) 跳知识图谱）+ 一句 B 的知识解读。研究由自动化按 C2 审核标准 S9 每日 best-effort 挂载，须与对应解读/新闻直接相关，无研究时该解读不渲染此块。不新增图谱节点。
  4. 关联理论按钮（⤢） — 点击弹出局部网络弹窗：以该理论为中心、1跳关联节点按圆周排布的网状子图（Canvas 渲染，连线同款渐变流动）；弹窗内可悬停高亮、点击任意节点查看富化详情；底部「在知识图谱中展开 →」可一键跳转主图并定位选中该节点。
    • 🧩 概念中文映射：详情中的核心概念/关联理论优先显示中文名，未匹配节点时经 CONCEPT_LABELS 映射表兜底（如 liquid_modernity→液态现代性），不再出现裸英文 id。
    • 📐 Canvas 自适应缩放：drawModal 按当前画布尺寸自动计算缩放系数，保证所有节点（含半径+标签）100% 落在画布内可点击；resizeTmCanvas 在弹出动画结束后补测，并接 ResizeObserver 响应窗口/响应式变化。
    • 🎯 打开即选中：弹窗打开时自动选中你点击的关联理论节点（中心节点），右侧详情区直接渲染该理论的完整释义（思想家：著作+思想+关联理论；理论：一句话理解+深入解读+代表人物+核心概念；概念：解释+生活例子），无需再点一次；点击图中其他节点可即时切换查看。
    • 🎨 详情样式对齐 A14：弹窗内节点详情的 .tp-* 样式已全局化，与 [A14] 知识节点详情卡片 完全一致（类别药丸、著作/思想 chips、一句话理解高亮块、生活例子块、展开按钮等），两者共用同一套样式源，保证视觉统一。
      注：此前"按钮对齐 A11 青色药丸"的决定被此统一取代——弹窗内小按钮现采用 A14 的中性描边风（hover 转红），不再单独使用 A11 青色。
    • 📏 分栏稳定：弹窗左右分栏加 min-width:0，flex 比例固定 1.2:1，内容少时右侧详情不会被左侧图区挤压消失。

[A5] 知识图谱 Canvas

📍 知识图谱页面 · 全屏 Canvas 区域 HTML5 Canvas + JS (C3)

使用 HTML5 Canvas 绘制 311个节点（社会学107·经济学102·心理学102）与 约638条连线（含跨学科桥接边，以及概念↔概念、思想家↔思想家两类同级直连）。布局采用力导向有机布局（Obsidian 风格），学科不做页面级分带、仅以节点外环颜色区分，支持拖拽平移 + 滚轮缩放。核心机制：

  • 力导向：每帧 tick() 执行斥力 + 连线弹簧 + 居中力 + 学科聚类力（非时间轴模式：把同属一学科的节点拉向该学科横向锚点 W×0.2/0.5/0.8，使三学科分成左右三簇；居中力横向分量相应减弱到 *0.4 让聚类力主导横向分布）+（可选）时间轴 X 软约束；alpha 随节点数自适应冷却，进入页面约 0.5s 停稳；单帧速度设 VMAX 上限防爆炸。边界为宽松世界盒 [-W,2W]×[-H,2H]（v1.24 起，原为死夹屏幕条盒 [0,W]×[0,H]），节点可自由铺散、靠平移/缩放探索。视角：进入页面（桌面+移动统一）自动 fitToView() 按可见节点包围盒铺满视口（初铺 + 收敛后精铺两次）；右下角「⟳ 全图」按钮一键复位。
  • 播种：初始采用洗牌式网格播种（确定性打散网格单元、三学科交错混排），节点自然聚簇、互不重叠。
  • 时间轴：开启时直接将节点 X 预置到年份位置（Y 不变），杜绝贴角聚集；刻度仅在有节点的 50 年段绘制，不显示无节点的空白年段。
  • 连线渲染：按关联强度 s 分层（强关联更粗更亮、弱关联更细更淡）；同级直连边在 addE 内无向去重（同对边保留较强强度 s）。
  • 跨学科成网：学科间跨科边 34 条（心理学贡献 26，含"社会化"节点与精神分析/本我自我超我/依恋/刻板印象/损失厌恶等桥接），三科真正成网。
  • 视觉增强：叠加渐变发光节点、流动虚线连线、正弦浮动动画等。

节点颜色规则：

  • 节点本体：思想家=深蓝(#3D4F8F)、理论=红(#C84B3A)、概念=青(#3A8C8C)、领域=紫(#8B7EC8)。
  • 学科外环：社会学=蓝(#5B6FB5)、经济学=金(#D4A017)、心理学=绿(#2FA37C)——外环加粗至 4px 并带轻微同色发光。

📇 四类节点的卡片内容（页面可纵向滑动，篇幅不限）

🔗 词条标题链接到维基百科

卡片标题已变为可点击链接，指向该词条对应的维基百科页面（优先中文维基，无中文词条时回退英文维基），新标签页打开。数据通过 Wikipedia API 批量获取并写入 NODE_META，在 initNodes 中随 ENRICH 一并合并进 node.data.wiki；思想家头像 URL 同样来自 Wikipedia（node.data.photo），图片加载失败时经 onerror 自动回退到首字初始头像。
